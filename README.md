# Chetna Ghorela — Portfolio

A responsive personal portfolio built with HTML, CSS and JavaScript.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a public repository named `portfolio` (or any name you prefer).
2. Upload **all files and the `assets` folder**, keeping the folder structure.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
5. Your site will appear at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Before publishing
- Check that your email, education wording, dates and all certificate details are accurate.
- The LinkedIn Learning and Coursera/YBI images were supplied as screenshots; review the cropped certificate previews for readability.
- Add direct GitHub repository links to each project when you have them.
- The Skincare Analyzer is labelled as a concept; update its description as the project develops.
- This site links to your resume preview image. Replace it with a PDF if you have a final PDF resume you want recruiters to download.
